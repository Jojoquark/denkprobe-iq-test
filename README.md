# Denkprobe – IQ-Test

Kostenloser IQ-Test als statische Seite (eine Datei: `index.html`).

- 35 Aufgaben in 3 Teilen (Matrizen, Zahlenreihen, Sprache & Logik), je mit Zeitlimit
- Auswertung mit 3-Parameter-IRT-Modell (EAP), Ergebnis mit 90 %-Konfidenzintervall
- Vergleich: internationale Norm, Deutschland, Schweden, USA
- Keine Daten verlassen den Browser

## Auf GitHub Pages veröffentlichen

1. Neues Repository anlegen, `index.html` hochladen.
2. Settings → Pages → Source: „Deploy from a branch“, Branch `main`, Ordner `/ (root)`.
3. Nach ca. 1 Minute ist die Seite unter `https://<nutzername>.github.io/<repo>/` erreichbar.

## Ehrlicher Hinweis

Die Aufgabenparameter sind an veröffentlichte Befunde angelehnt, aber nicht an einer eigenen
Normstichprobe geeicht. Das Ergebnis ist eine fundierte Schätzung, kein klinischer Befund.
